Minimum Spanning Trees: Kruskal and Prim

A minimum spanning tree connects every vertex of a weighted, undirected graph using the smallest possible total edge weight. Kruskal grows a forest by taking the lightest edge that doesn’t form a cycle, using disjoint sets. Prim grows one tree from a start vertex, always adding the cheapest edge leaving it, using a priority queue.
